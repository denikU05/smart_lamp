# Проект IoT: "Прототип умного освещения"


Проект на базе чипа ESP32. На чип загружена программа `main.cpp`. Уровень лампы
регулируется обратно пропорционально входящему сигнала фоторезистора со смещением `offset`

Чип связывается с сервером: отправляет туда данные об уровне и получает команду (режим и значение)

На сервере поднят телеграм-бот, с помощью которого происходит задание режима: автоматический или ручной. В боте
отображается текущее состояние и время последнего обновления.

При потере связи чипа с сервером, чип продолжает работу в автономном режиме в соответствии с последним обновлением.
